Week 4 – Web Scraping Project

Overview

This folder contains my Week 4 web scraping project, where I collected and organised health insurance and healthcare provider information from Nigeria, England, and Wales.

Objectives

- Scrape healthcare provider information from online sources
- Collect details such as organisation name, website, location, contact information, and services
- Clean and standardise the collected data
- Check for duplicates and missing values
- Combine the data into a final structured dataset

Tools Used

- Python
- Jupyter Notebook
- Pandas
- BeautifulSoup
- Requests

Final Output

The final dataset contains 117 healthcare organisationsfrom Nigeria and the United Kingdom..
